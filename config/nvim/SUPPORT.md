# Support

We are glad you are using our Neovim configuration! If you need help, please follow these steps:

## 1. Documentation
Please read the README.md and check out the documentation within the repository. Many common questions are answered there.

## 2. GitHub Issues
If you have found a bug or have a feature request, please open an issue on our GitHub repository:
https://github.com/xscriptor-colors/nvim/issues

Before opening a new issue, please search existing issues to see if your problem has already been reported by someone else.

## 3. Contact
For private or sensitive support inquiries, you can reach out directly via email at x@xscriptor.com.
