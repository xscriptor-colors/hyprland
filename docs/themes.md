# Dynamic Color System (Matugen)

This configuration uses Matugen to generate all UI colors dynamically from the current wallpaper. There are no static color themes -- every component's palette is derived from the wallpaper image via Material You color extraction.

## Color Generation Pipeline

1. User selects a wallpaper via the wallpaper picker (SUPER + W)
2. `awww` sets the wallpaper with a transition animation
3. `matugen_reload.sh` copies the wallpaper to a persistent cache and runs `matugen image <wallpaper> --source-color-index 0`
4. Matugen renders all templates defined in `~/.config/matugen/config.toml`
5. `reload.sh` sends IPC to QuickShell to refresh QML colors and copies SDDM colors to the system directory

## Template Outputs

| Template | Output | Component |
|----------|--------|-----------|
| `hyprland.conf.template` | `~/.config/hypr/colors.conf` | Hyprland decorations and borders |
| `qs_colors.json.template` | `~/.config/hypr/scripts/quickshell/qs_colors.json` | All QML widgets (loaded via MatugenColors.qml) |
| `kitty-colors.conf.template` | `~/.config/kitty/kitty-matugen-colors.conf` | Kitty terminal (included from kitty.conf) |
| `nvim-colors.lua.template` | `~/.config/nvim/matugen_colors.lua` | Neovim editor |
| `cava-colors.ini.template` | `~/.config/cava/colors` | Cava audio visualizer |
| `swayosd.css.template` | `~/.config/swayosd/style.css` | On-screen display overlay |
| `gtk.css.template` | `~/.cache/matugen/colors-gtk.css` | GTK3/GTK4 applications |
| `qtct.conf.template` | `~/.config/qt5ct/colors/matugen.conf` and `~/.config/qt6ct/colors/matugen.conf` | Qt application widget colors |
| `qt-style.qss.template` | `~/.config/qt5ct/qss/matugen-style.qss` and `~/.config/qt6ct/qss/matugen-style.qss` | Qt application stylesheet |
| `sddm-colors.qml.template` | `~/.config/hypr/sddm-colors.qml` | SDDM login screen (copied to system dir) |

## MatugenColors QML Singleton

The `MatugenColors.qml` file defines color properties with Catppuccin Mocha defaults. At runtime, `qs_colors.json` (generated by Matugen) overrides these defaults. The singleton exposes named color properties (`base`, `text`, `surface0`, `mauve`, `blue`, `red`, etc.) used by all QML widgets.

## Hyprland colors.conf

Matugen generates `~/.config/hypr/colors.conf` which is sourced at the top of `hyprland.conf`. This file defines variables used for:

- Window border colors (active and inactive)
- Workspace indicator colors
- General UI accent colors
