# Hyprland Configuration

The Hyprland configuration is modular, using `source =` directives to split settings across multiple files.

## Configuration Files

| File | Purpose |
|------|---------|
| `hyprland.conf` | Main entry point. Sets monitors, input, general, decoration, layout, gestures, misc, and xwayland settings. Sources all other config files. |
| `env.conf` | Environment variables: NVIDIA GBM backend, Wayland session type, Qt/GTK/SDL backends, Electron Wayland flags, cursor theme, wallpaper directory. |
| `keybinds.conf` | All keybindings organized by category: applications, QuickShell widgets, window management, lock/power, screenshots, multimedia, focus/movement, workspaces, multi-monitor, GPU mode, theme. |
| `animations.conf` | Bezier curves (smooth, overshot, easeInOutQuart, etc.) and animation definitions for windows (open/close/move), fades, borders (with angle loop), workspaces, and special workspaces. |
| `windowrules.conf` | Window rules: floating windows (system dialogs, file dialogs, PiP), centering, size constraints, per-class opacity, workspace assignments (browser WS2, editor WS3, communication WS4, media WS5, games WS6), game fullscreen and tearing. |
| `workspaces.conf` | Multi-monitor workspace binding (commented presets for primary/secondary monitor), special workspaces (scratchpads: terminal, files, music). |
| `autostart.conf` | System services (keyring, polkit, xdg-desktop-portal), UI components (awww wallpaper daemon, QuickShell Shell.qml, focus daemon, init, settings watcher, guide, playerctld, swayosd), utilities (cliphist, nm-applet, blueman, hypridle, volume listener, update notifier), cursor/GTK theme. |
| `config/variables.conf` | Core variables: `$mainMod = SUPER`, `$terminal = kitty`. |
| `config/settings.conf` | QML-specific settings: font family (Hack Nerd Font), ecosystem flags (no update news, no donation nag). |
| `config/monitors.conf` | Generated by `settings_watcher.sh` or `detect-monitors.sh`. Contains per-monitor config with resolution, refresh rate, position, and scale. |
| `colors.conf` | Generated by Matugen. Contains dynamic color variables sourced at the top of hyprland.conf. |

## Modular Architecture

```
hyprland.conf
  +-- colors.conf (Matugen-generated)
  +-- env.conf
  +-- config/variables.conf
  +-- keybinds.conf
  +-- animations.conf
  +-- windowrules.conf
  +-- autostart.conf
  +-- workspaces.conf
  +-- config/settings.conf
  +-- config/monitors.conf (generated)
```

## Template-based Dynamic Config

Settings changed via the QuickShell settings panel are written to `settings.json`. The `settings_watcher.sh` daemon watches this file and regenerates the following from templates in `templates/`:

- `env.conf` from `env.conf.template` -- injects wallpaper dir, hardware envs, XDG dirs
- `config/settings.conf` from `settings.conf.template` -- injects KB layout and options
- `autostart.conf` from `autostart.conf.template` -- appends user-defined startup commands and guide toggle
- `config/keybindings.conf` from `keybinds.conf.template` -- appends user-defined keybinds
- `config/monitors.conf` from `monitors.conf.template` -- generates monitor lines from stored resolution/position/rate/scale

Only files that actually change trigger a `hyprctl reload` to avoid display flicker.

## Auto Monitor Detection

On session start, `detect-monitors.sh` runs via `exec-once` in `autostart.conf`. It queries `hyprctl monitors -j` and for each monitor selects the resolution and refresh rate mode with the highest available refresh rate, writing the result to `config/monitors.conf`.

This ensures that:
- Monitors capable of high refresh rates (120Hz, 144Hz, 165Hz, 240Hz, etc.) are automatically set to the maximum rate without manual configuration.
- The same dotfiles work across machines with different monitor capabilities -- a 60Hz laptop panel gets 60Hz, a 144Hz panel gets 144Hz.
- The settings panel (QuickShell) can override these values at any time via `settings.json`, which takes priority when present.
- When `settings.json` has no monitors defined (fresh install or reset), `settings_watcher.sh` falls back to `detect-monitors.sh` instead of using `preferred` (which typically defaults to 60Hz).

### Detection script

```
scripts/detect-monitors.sh
```

Generates `~/.config/hypr/config/monitors.conf` with entries like:
```
monitor = eDP-1, 1920x1080@144, 0x0, 1
monitor = HDMI-A-1, 1920x1080@60, 1920x0, 1
```
